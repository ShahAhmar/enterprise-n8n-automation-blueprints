# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability or credential exposure risk, report it responsibly:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Report privately via email to: **shahahmar882@gmail.com**
3. Include workflow identifier, node configuration details, and reproduction steps.
